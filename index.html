Cloud Computing

Cloud computing means renting computing power over the internet instead of owning and maintaining physical machines yourself. When I open a cloud service, I can get servers, storage, databases or ready-made software within minutes, and I only pay for what I actually use. The provider takes care of the data centers, electricity, cooling and hardware repairs, so I can focus on building my application.

The biggest advantages are flexibility and speed. If my website suddenly gets more visitors, the platform can scale up automatically, and when traffic drops it scales back down. Resources are also available from anywhere in the world, which makes it easy to share work with other people. Of course, the cloud depends on a good internet connection and requires careful handling of security and cost.

03

Cloud Services

The three classic service models differ in how much the provider manages for you.

IaaS

Infrastructure as a Service

The provider gives me virtual machines, storage and networking. I choose the operating system and install and manage everything above it.

Example Amazon EC2

I manage: OS, runtime, app, data
PaaS

Platform as a Service

A ready-to-use platform for building and running applications. I upload my code and the provider handles servers, operating system and scaling.

Example AWS Elastic Beanstalk

I manage: app and data
SaaS

Software as a Service

Complete software delivered through the browser. I just sign in and use it, while the provider runs and updates everything behind the scenes.

Example Google Docs

I manage: my own content
